# Mintly

## Как отвечать

**Главное правило: ответ — это либо одна команда для сервера целиком (если
человеку нужно что-то ввести руками), либо одно слово «Сделал». Больше ничего.**

Ноль бесполезного текста. Только готовая работа.

- **Максимум два предложения в ответе. Всегда, без исключений.**
- Никаких вступлений, пересказов задачи, планов вслух и итоговых резюме.
- Сделал — коротко сказал что. Не объяснять то, о чём не спрашивали.
- Ответ по-русски.
- Причину и разбор писать, только если что-то сломалось или пользователь спросил «почему».
- SQL и команды, которые нужно выполнить руками, присылать в ответе целиком.
  Не отсылать к файлу в репозитории — человек читает с телефона.

## Проект

Telegram Mini App: запуск мемкоинов на TON, своя бондинг-кривая на Tact.
Весь интерфейс — один файл `src/App.tsx`. Серверная часть — `api/`.

## Работа с кодом

- Комментарии по-русски, объясняют «почему», а не «что».
- Каждое изменение: собрать (`npm run build`), проверить в браузере
  (playwright-core + `/opt/pw-browsers/chromium`), закоммитить и запушить
  в `main` и `claude/animated-background-8k6z12`.
- Перехватчики Playwright: последний зарегистрированный проверяется
  первым — общий маршрут регистрировать раньше частного.
