# Mintly — agent-chorus reel (демо)

Трек: 120 BPM, 0.5с/доля, дроп 10.0с (синтез: assets/mk_track.py).
Промпт (один, объявлен в коде один раз): `launch my coin on TON`

| Часть | Время |
|---|---|
| I  prompt  | 0.0–3.0 |
| II chorus  | 3.0–10.0 (терминал 3.0, панель 5.6, поле 7.4, композер 8.8) |
| III reel   | 10.0–24.0 |
| IV command | 24.0–28.0 |

Сетка резов реля (снап к 30fps): 10,11,12,13 (шаг 1.0) → 14…19.5 (шаг 0.5, 12 резов) → 20…21.75 (шаг 0.25, 8 резов) → финальный кадр держится 22–24.
