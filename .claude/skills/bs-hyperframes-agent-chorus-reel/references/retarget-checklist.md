# Retarget checklist

Every line must pass before movement I is written. Paste the filled list into the handoff.

## 1. The four surfaces — four rights positions, not one

- [ ] For **each** of the four surfaces it is established in writing whether the caller owns
      it or it is a neutral original.
- [ ] Every neutral surface carries no third-party wordmark, product name, model chip, icon
      set, menu structure, or signature layout.
- [ ] The four differ from one another in **shape** — full-bleed, docked, inline, floating —
      not in borrowed identity.
- [ ] The deliverable states which surfaces are representative.
- [ ] No screen recording of a third-party tool is used.

## 2. The prompt is identical

- [ ] The prompt string is declared **once in code** and read by all four surfaces.
- [ ] It is short enough to type four times inside seven seconds — about 34 characters.
- [ ] It is the prompt a real user would type.
- [ ] Nothing about it varies between entries: not the wording, not the punctuation, not the
      capitalisation.

## 3. The outputs are real

- [ ] Eight to twelve outputs, all genuinely produced by the product.
- [ ] Weak ones were cut rather than included to reach a count.
- [ ] Each output does something small for its whole cut — nothing is a held still.
- [ ] No output contains a real customer name, private URL, or personal data.

## 4. The music carries the second half

- [ ] The track has a **real drop**, and it is licensed for the caller's distribution.
- [ ] `npx hyperframes beats` has been run and the grid written to `beats/`.
- [ ] The drop's timestamp is recorded to the frame in `STORYBOARD.md`.
- [ ] The tempo is recorded as seconds per beat.
- [ ] The cut grid is derived from the tempo, not chosen by eye.
- [ ] Every cut is snapped to a frame boundary.
- [ ] The music is mixed loud — this film's music is structural, not a bed.

## 5. The reel is built correctly

- [ ] Hard cuts only: no crossfades, wipes, or motion blur between outputs.
- [ ] One output visible per frame; every output starts from an explicit hidden state.
- [ ] The rate accelerates toward the end rather than running flat.
- [ ] The final output holds for at least two beats before the command.

## 6. The command works

- [ ] It has been run and works as written.
- [ ] It is correct for the audience's environment.
- [ ] Nothing animates after it — it is the last thing the audience should be looking at.

## 7. Rights and honesty

- [ ] Every surface shown is one the product genuinely works in.
- [ ] Nothing states or implies affiliation with, endorsement by, or authorization from any
      company the caller does not own.
- [ ] The caller owns or has licensed every supplied asset, including the track.
